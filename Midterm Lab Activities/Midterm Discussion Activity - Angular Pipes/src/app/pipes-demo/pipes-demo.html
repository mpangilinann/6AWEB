Angular Pipes Explorer

Data Transformation & Formatting Demo

Date Pipe

Formats a date value according to locale rules.

Short: {{ presentDate | date:'shortDate' }}
Full: {{ presentDate | date:'fullDate' }}
Custom (MM/dd/yyyy): {{ presentDate | date:'MM/dd/yyyy' }}

Async Pipe

Subscribes to an Observable and returns the latest emitted value.

{{ time$ | async | date:'h:mm:ss a' }}

Currency Pipe

Transforms a number to a currency string with correct symbols.

Default (USD): {{ price | currency }}
INR: {{ price | currency: 'INR' }}
PHP: {{ price | currency: 'PHP' }}

Slice Pipe

Creates a new array containing a subset (slice) of the elements.

Original: {{ Fruits | slice:0:3 }}...
Slice (1:4): {{ Fruits | slice:1:4 }}
Last 2: {{ Fruits | slice:-2 }}

Decimal Pipe

Formats a number as text with specific integer/fraction digits.

Raw: {{ decimalNum1 }}
Format (2.1-2): {{ decimalNum1 | number: '2.1-2' }}

Percent Pipe

Transforms a number to a percentage string.

Raw: {{ growthRate }}
Formatted: {{ growthRate | percent:'1.2-2' }}

TitleCase Pipe

Capitalizes the first letter of each word.

Before: {{ welcomeMessage }}
After: {{ welcomeMessage | titlecase }}

JSON Pipe

Converts a value into a JSON string. Useful for debugging.

{{ userObject | json }}
